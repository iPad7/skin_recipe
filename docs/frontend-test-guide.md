# Skin Recipe — 프론트엔드 수동 테스트 가이드

## 실행 환경

```bash
# 백엔드 (터미널 1)
cd /home/jaeboem/projects/skin_recipe
./gradlew bootRun

# 프론트엔드 (터미널 2)
cd /home/jaeboem/projects/skin_recipe/frontend
npm run dev
```

- 프론트엔드: `http://localhost:5173`
- 백엔드: `http://localhost:8080`
- 전제 조건: MySQL Docker 컨테이너 실행 중, `UPSTAGE_API_KEY` 환경변수 설정

---

## 테스트 계정

테스트 전 아래 계정을 미리 만들어두거나, TC-A01부터 순서대로 진행한다.

| 항목 | 값 |
|------|----|
| 이메일 | `test@example.com` |
| 비밀번호 | `password123` |
| 닉네임 | `테스터` |
| 피부타입 | 지성 (OILY) |
| 피부 고민 | 모공, 번들거림 |
| 알레르기 성분 | 향료 |

## TC-A: 인증 (Authentication)

### TC-A01 — 정상 회원가입

| 항목 | 내용 |
|------|------|
| 진입 | `/signup` 접속 |
| 입력 | 이메일: `test@example.com`, 비밀번호: `password123`, 닉네임: `테스터`, 피부타입: `지성`, 피부 고민: `모공, 번들거림`, 알레르기: `향료` |
| 기대 결과 | `/login` 페이지로 이동 |

### TC-A02 — 이미 존재하는 이메일로 회원가입

| 항목 | 내용 |
|------|------|
| 전제 | TC-A01 완료 (동일 이메일 계정 존재) |
| 입력 | 동일 이메일로 재가입 시도 |
| 기대 결과 | 폼 하단에 에러 메시지 표시, 페이지 이동 없음 |

### TC-A03 — 피부타입 미선택 회원가입

| 항목 | 내용 |
|------|------|
| 입력 | 피부타입 미선택 상태로 회원가입 버튼 클릭 |
| 기대 결과 | `"피부 타입을 선택해주세요."` 에러 메시지 표시 |

### TC-A04 — 정상 로그인

| 항목 | 내용 |
|------|------|
| 전제 | TC-A01 완료 |
| 입력 | `test@example.com` / `password123` |
| 기대 결과 | `/` (홈) 으로 이동, 대시보드 표시 |

### TC-A05 — 잘못된 비밀번호 로그인

| 항목 | 내용 |
|------|------|
| 입력 | `test@example.com` / `wrongpassword` |
| 기대 결과 | 에러 메시지 표시, 페이지 이동 없음 |

### TC-A06 — 미인증 상태로 보호된 경로 직접 접근

| 항목 | 내용 |
|------|------|
| 조건 | 로그아웃 상태 (localStorage 토큰 없음) |
| 동작 | `/cosmetics` 직접 URL 입력 |
| 기대 결과 | `/login` 으로 리다이렉트 |

### TC-A07 — 새로고침 후 로그인 상태 유지

| 항목 | 내용 |
|------|------|
| 전제 | 로그인된 상태 |
| 동작 | 브라우저 새로고침 (F5) |
| 기대 결과 | 로그아웃되지 않고 현재 페이지 유지 |

### TC-A08 — 로그아웃

| 항목 | 내용 |
|------|------|
| 전제 | 로그인된 상태 |
| 동작 | 사이드바 하단 `로그아웃` 버튼 클릭 |
| 기대 결과 | `/login` 으로 이동, 재접속 시 인증 만료 |

### TC-A09 — 회원 탈퇴 정상 흐름

| 항목 | 내용 |
|------|------|
| 전제 | 로그인 상태, 화장품·루틴·채팅 데이터 1개 이상 존재 |
| 동작 | 홈 → 프로필 카드 `편집` → 모달 하단 `회원 탈퇴` 링크 클릭 → 확인란에 `회원탈퇴` 입력 → `탈퇴하기` 클릭 |
| 기대 결과 | API 호출 성공 → 자동 로그아웃 → `/login` 리다이렉트, 해당 계정으로 재로그인 불가 |

### TC-A10 — 회원 탈퇴 확인 텍스트 불일치 시 버튼 비활성화

| 항목 | 내용 |
|------|------|
| 동작 | `회원 탈퇴` 링크 클릭 후 확인란에 `탈퇴` (불완전 텍스트) 입력 |
| 기대 결과 | `탈퇴하기` 버튼 비활성화(연한 빨간색), 클릭 불가 |

## TC-C: 채팅 (Chat)

### TC-C01 — 첫 메시지 전송 시 세션 자동 생성

| 항목 | 내용 |
|------|------|
| 전제 | 홈(`/`) 대시보드 상태 |
| 동작 | 입력창에 `"내 피부에 맞는 화장품 추천해줘"` 입력 후 Enter 또는 전송 버튼 클릭 |
| 기대 결과 | URL이 `/chat/{sessionId}` 로 변경, 대시보드가 채팅 뷰로 전환, **사용자 메시지 말풍선이 즉시 표시됨**, AI 응답 로딩 스피너 → 응답 말풍선 표시 |

### TC-C02 — 연속 메시지 전송

| 항목 | 내용 |
|------|------|
| 전제 | TC-C01 완료 (채팅 세션 존재) |
| 동작 | 추가 메시지 입력 및 전송 |
| 기대 결과 | 기존 세션 유지, 새 세션 미생성, 메시지 누적 표시, 자동 스크롤 |

### TC-C03 — Enter 키로 전송 / Shift+Enter 줄바꿈

| 항목 | 내용 |
|------|------|
| 동작 1 | 텍스트 입력 후 `Enter` 키 |
| 기대 결과 1 | 메시지 전송 |
| 동작 2 | 텍스트 입력 후 `Shift+Enter` |
| 기대 결과 2 | 줄바꿈, 전송 안 됨 |

### TC-C04 — AI 응답 로딩 중 입력 비활성화

| 항목 | 내용 |
|------|------|
| 동작 | 메시지 전송 후 응답 대기 중 추가 입력 시도 |
| 기대 결과 | 입력창과 전송 버튼 비활성화 (disabled) |

### TC-C05 — 사이드바 세션 목록 갱신

| 항목 | 내용 |

| 전제 | TC-C01 완료 |
| 기대 결과 | 사이드바에 새 세션이 `오늘` 그룹에 표시됨 |

### TC-C06 — 사이드바 세션 클릭으로 히스토리 복원

| 항목 | 내용 |
|------|------|
| 전제 | 2개 이상의 채팅 세션 존재 |
| 동작 | 다른 세션을 사이드바에서 클릭 |
| 기대 결과 | URL이 해당 세션의 `/chat/{sessionId}` 로 변경, 해당 세션의 채팅 히스토리 표시 |

### TC-C07 — 사이드바 세션 삭제

| 항목 | 내용 |

| 기대 결과 | 세션 목록에서 제거, 현재 해당 세션을 보고 있었다면 `/` 로 이동 |

### TC-C08 — 새 채팅 버튼

| 항목 | 내용 |
|------|------|
| 동작 | 사이드바 상단 `+ 새 채팅` 버튼 클릭 |
| 기대 결과 | `/` 로 이동, 대시보드 뷰로 복귀 |

### TC-C09 — RAG 응답 품질 확인

| 항목 | 내용 |
|------|------|
| 전제 | 화장품 등록된 상태 |

| 항목 | 내용 |

| 주의 | 분석 결과 확인 폼이 나타나면 ❌ (버그 재발) |

### TC-P07b — 이미지로 화장품 추가 (low confidence)

| 항목 | 내용 |
|------|------|
| 동작 | 화질이 낮거나 성분 인식이 불분명한 이미지 업로드 → `이미지 분석` 클릭 |
| 기대 결과 | 분석 결과 확인 폼으로 전환, 파싱된 제품명·브랜드·성분 자동 입력 → 수정 후 `저장` 클릭 시 목록에 추가 |

### TC-P08 — 이미지 미선택 시 에러

| 항목 | 내용 |
|------|------|
| 동작 1 | 앞면·뒷면 모두 미선택 상태로 `이미지 분석` 클릭 |
| 기대 결과 1 | `"앞면과 뒷면 이미지를 모두 선택해주세요."` 에러 메시지 |
| 동작 2 | 앞면만 선택 후 `이미지 분석` 클릭 |
| 기대 결과 2 | 동일 에러 메시지, 전송 안 됨 |
